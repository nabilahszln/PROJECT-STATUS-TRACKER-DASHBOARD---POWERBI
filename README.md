📌 Project Overview:

This project focuses on developing an interactive dashboard for monitoring project progress, payment tracking, and project timelines using Microsoft Power BI and Microsoft Excel.
The dashboard was designed to improve visibility of ongoing projects, reduce manual tracking, and support faster decision-making through real-time project insights.

🚨 Problem Statement:

Managing multiple ongoing projects manually can lead to:

- Missing progress updates
- Delayed reporting
- Limited visibility of project timelines
- Difficulty tracking payment status
- Inefficient monitoring of project stages
Without a centralized monitoring system, project teams may struggle to identify delays and monitor financial progress effectively.

🎯 Project Objectives:

- To develop a user-friendly dashboard that provides clear visibility of overall project 
progress and current project status.
- To track payment milestones and payment status to support accurate financial 
monitoring and timely updates. 
- To monitor project timelines and stages in order to identify potential delays and support 
proactive decision-making. 

🛠️ Tools & Technologies
Microsoft Power BI
Microsoft Excel
Power Query
DAX (Data Analysis Expressions)
